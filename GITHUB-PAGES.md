# Публикация на GitHub Pages

1. На GitHub нажмите **+** → **New repository**.
2. Введите имя `kotoba-japanese-trainer`, выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Перетащите все файлы из папки `japanese-trainer` (включая папку `icons`) и нажмите **Commit changes**.
5. Откройте **Settings** → **Pages**.
6. В разделе **Build and deployment** выберите **Deploy from a branch**.
7. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
8. Через несколько минут ссылка появится в верхней части раздела Pages.

На iPhone откройте опубликованную ссылку в Safari, нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.
