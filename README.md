# ことば

Офлайн-PWA для повторения японских слов. Приложение не требует сервера и подходит для GitHub Pages.

## Возможности

- 78 стартовых слов без предложений;
- три режима тренировки;
- интервальное повторение и отдельное повторение ошибок;
- статистика и серия дней;
- добавление собственных слов;
- экспорт и импорт резервной копии;
- офлайн-режим и установка на главный экран.

## Локальный запуск

Откройте папку через любой статический веб-сервер. Например: `python3 -m http.server 8080`.

## GitHub Pages

Загрузите содержимое этой папки в корень репозитория. В настройках репозитория откройте **Pages**, выберите **Deploy from a branch**, ветку **main** и папку **/(root)**.
